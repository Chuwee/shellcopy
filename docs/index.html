How it works

		
Narrow down fast, then point exactly

		
Two steps, or one if you jump by id. Your hands never leave the keyboard.

		

			

				1 · halve
				
Halve the screen

				
Every word on screen starts in play. Each arrow keeps the half it points at. Empty space never costs a press, and 100 near-identical IPs take about 7.

			

			

				2 · point
				
Point and select

				
When one word is left, a cursor lands on it. Move by character, word or line, press Enter to start selecting and Enter again to copy.

			

			

				tab · ids
				
Or pick both ends by id

				
Press Tab for ids mode: short ids appear in front of the words. Type one to start the selection there and another to end it there, then press Enter. Shift+id copies right away. Tab switches back, and cy --ids starts in this mode.

			

		

	






	

		
Under the hood

		
Built for real terminals

		
No terminal plugin and no special emulator. It reads what your terminal already shows.

		

			

				
Any shell

				
cy is a plain command that works in bash, zsh, fish, ksh, dash, nushell and others. bash, zsh and fish also get a small optional hook.

			

			

				
Scrollback included

				
The hook records what the terminal prints, so cy can pick from anything still in the scrollback, not only what's visible. Inside tmux it reads tmux's screen directly.

			

			

				
Private by design

				
The recording is text only, with no keystrokes. It's readable only by you (kept in memory on Linux, in your private temp folder on macOS), trimmed past 8 MB, and deleted when the terminal closes.

			

			

				
Pipes too

				
cmd | cy picks from a command's output, and x=$(cmd | cy --print) puts the selection in a variable.

			

			

				
Your clipboard

				
Copies with wl-copy, xclip, xsel or pbcopy. Without them, it uses OSC 52, which also works over SSH.

			

			

				
Small and open

				
One Python file and one dependency (pyte). MIT licensed.

			

		

	






	

		
Get it

		
Install

		
The script does everything. With Homebrew or apt, run shellcopy setup once afterwards.


		

			
			
			
			
		

		

			
Linux and macOS, no sudo. Installs into ~/.local and adds the hook to your bash, zsh and fish rc files, so there's nothing else to set up. Run it again to update.

			
curl -fsSL https://chuwee.github.io/shellcopy/install.sh | sh

			
To leave your rc files alone: curl -fsSL https://chuwee.github.io/shellcopy/install.sh | sh -s -- --no-rc. You can also read the script first.

		

		

			
macOS and Linux.

			
brew install chuwee/shellcopy/shellcopy

		

		

			
Download the .deb from the latest release, then:

			
sudo apt install ./shellcopy_*_all.deb

		

		

			
The installer also adds the hook to ~/.bashrc, ~/.zshrc and fish's conf.d, for whichever of them are installed.

			
git clone https://github.com/Chuwee/shellcopy
cd shellcopy && ./install.sh

		


		

			
With Homebrew or apt: one more command

			
Packages can't edit your shell's rc files, so run this once afterwards. (The script above does it for you.) It adds the hook for bash, zsh and fish, and running it again is harmless. shellcopy setup --remove takes the hook out.

			
shellcopy setup

			

				What it adds, or how to do it by hand
				
Without the hook, cmd | cy still works, and so does plain cy inside tmux. With it, plain cy works in any terminal.

				
# ~/.bashrc  (in ~/.zshrc, use: shellcopy init zsh)
command -v shellcopy >/dev/null && eval "$(shellcopy init bash)" && shellcopy record

				
# ~/.config/fish/conf.d/shellcopy.fish
status is-interactive; and type -q shellcopy; and shellcopy init fish | source; and shellcopy record

				
# any other shell: recording only
shellcopy record --check && exec shellcopy record
