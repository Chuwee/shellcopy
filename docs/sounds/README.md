# Demo sounds

Optional sound files for the before/after demo on `index.html`. Each one overrides a synthesized default; a missing file falls back to the synth.

- `click.mp3`: a mouse button click (pitch varies slightly per play)
- `key.mp3`: one mechanical keyboard key press (pitch varies slightly per play)
- `enter.mp3`: the Enter key, deeper
- `faah.mp3`: "FAAAH", the milder outburst on the third miss (~2.2s, loudest at the start)
- `scream.mp3`: "FFFFUUUU", the finale (~2.2s, loud from the start; the screen breaks 0.15s in)
- `shatter.mp3`: the screen breaking
